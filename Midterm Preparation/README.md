# Midterm Preparation: Weeks 2-5

Twenty exercises to practise the concepts demonstrated in weeks 2 through 5. Work through them in order, or select a topic you need to revisit. These are practice questions, not an official exam outline or an answer key.

## How to practise

1. Open an exercise and **copy its starter code into your own `.py` file** in a personal practice folder.
2. Read the problem, input assumptions, and requirements. Predict the supplied check cases before writing code.
3. Complete the TODO sections in your copy. The starters are valid Python but intentionally incomplete; running one unchanged will not produce the required solution.
4. Run your program and compare the results with **Check your work** in the comments. Add at least one test of your own.
5. Trace unexpected results by hand, paying attention to types, branch order, loop conditions, and where counters change.

Use Python 3; no extra packages are needed. From the folder containing your personal copy, run `python3 my_exercise.py` (or `py my_exercise.py` on Windows). Replace the filename with your own. You can also use your editor's Run command.

Early questions state valid-input assumptions so you can concentrate on the core concept. Later questions explicitly require validation. A `pass` line is a temporary placeholder: replace it with your implementation. Do not run an unfinished `while` loop without a way to make progress and stop.

## Scope and self-check

Exercises 01-04 revisit week 2 algorithms, including the basic list traversal and linear search shown in those demos. Exercises 05-09 focus on week 3 data and strings; 10-14 on week 4 selection and validation; 15-20 on week 5 iteration. Later exercises also reuse earlier skills. No custom functions, GUI programming, file processing, nested loops, or advanced collection operations are needed.

For each completed exercise, check that you can explain the inputs, each calculation or condition, and the output. Try relevant boundaries such as zero, the exact threshold, the first and last loop values, or an empty collection. Only test invalid input where the exercise requires handling it; otherwise note the stated assumption.
